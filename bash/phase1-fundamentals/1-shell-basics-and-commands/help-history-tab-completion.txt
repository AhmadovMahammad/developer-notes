Help, History, and Tab Completion

You're working in the terminal now. You know some basic commands. 

But here's the problem: there are hundreds of commands, and each command has many options. How do you remember them all?

The answer is: you don't have to.

Bash gives you tools to discover, remember, and reuse commands without memorizing everything.

Getting Help When You're Stuck



-- Let's say you want to use a command called ls, but you don't remember what it does or what options it has.

There are two main ways to get help.

1. The man Command

The word "man" is short for "manual". Every command in Linux comes with a manual page that explains what it does.

You type:

man ls

And suddenly your screen fills with documentation. It shows you what ls does, all the flags you can use, and examples.

You can scroll up and down using the arrow keys. When you're done reading, press q to quit and go back to your normal prompt.

The manual pages are very detailed. Sometimes they're too detailed. 

But they are always there, and they are official documentation written by the people who made the command.

The --help Flag

Most commands also support a shorter help option. You add --help after the command name.

2. ls --help

This shows you a quick summary. It's not as detailed as man, but it's faster and easier to read. 

It usually shows you the most common options and a brief explanation.

Some commands use -h instead of --help. It depends on the command. But most modern commands support --help.

When should you use which?

Use --help when you just need a quick reminder. Use man when you need to understand something deeply or see all available options.



-- Remembering What You Typed Before

You're typing commands all day. Sometimes you type the same command ten times. Do you really have to retype it every single time?

No. Bash remembers everything you type.

The history Command

Type this:

history

You'll see a numbered list of every command you've typed recently. It might show hundreds of lines.

Each line has a number on the left, and the command on the right.

Why is this useful?

Because now you can see what you did yesterday, or an hour ago, or five minutes ago. If you forgot how you did something, just look at your history.

You can also rerun a command from history without retyping it. If you see a command at line number 42, you can type:

!42

And Bash will run that exact command again.

Or you can type:

!!

This repeats the last command you ran. It's very useful when you need to do something twice in a row.



-- Searching Your History

Let's say you typed a long command yesterday, and you want to run it again. But you don't want to scroll through 500 lines of history to find it.

Press Ctrl + R on your keyboard.

You'll see the prompt change. It says something like:

(reverse-i-search)`':

Now start typing part of the command you're looking for. Let's say you type mkdir.

Bash will search backwards through your history and show you the most recent command that contains the word "mkdir".

If that's not the one you want, press Ctrl + R again. It will show you the next match. Keep pressing Ctrl + R until you find the right command.

When you find it, press Enter to run it. Or press the right arrow key to put it on your command line so you can edit it before running.

This is incredibly powerful. Once you get used to it, you'll use it constantly.



-- Tab Completion

This is where things get magical.

Let's say you want to go into a folder called my-very-long-folder-name.

You could type:

cd my-very-long-folder-name

But that's a lot of typing. And if you make one mistake, the command fails.

Instead, type this:

cd my

And then press the Tab key.

If there's only one folder that starts with "my", Bash will automatically complete the rest of the name for you. The full command appears on your screen:

cd my-very-long-folder-name

You didn't have to type it. Bash did it for you.

What If There Are Multiple Matches?

Let's say you have three folders:

    my-folder
    my-project
    my-test

You type:

cd my

And press Tab.

Nothing happens, because Bash doesn't know which one you want.

Press Tab again (double-tap it).

Bash shows you a list of all the possibilities:

my-folder  my-project  my-test

Now you type a bit more to make it unique. Let's say you type:

cd my-p

And press Tab again.

Now it completes to my-project, because that's the only match.




-- Tab Completion Works for Commands Too

Let's say you want to run a command that starts with hist, but you don't remember the full name.

Type:

hist

And press Tab twice.

Bash shows you all commands that start with "hist". You'll probably see:

history

Now you know the command exists, and you can finish typing it or let tab-completion do it for you.

Why This Matters

Tab completion saves time. But more importantly, it prevents typos. If you type a filename wrong, your command fails. 

If you let tab-completion do it, you know the file exists and the name is correct.

It also helps you discover what's available. 

If you don't remember exact names, you can start typing and let tab-completion show you the options.
Putting It All Together

Imagine you're working on a project. You created a folder a few days ago with a long name. You want to go into that folder now.

You don't remember the exact name. So you type:

cd proj

Press Tab. It completes to project-final-version-3.

You press Enter and you're inside the folder.

Now you want to list all the files, but with details. You remember ls has an option for that, but you don't remember which one.

You type:

man ls

You scroll down and see that -l gives you a detailed list.

You press q to exit the manual.

You type:

ls -l

Later, you want to run that command again. Instead of retyping it, you press the up arrow key. Your last command appears. You press Enter.

Or maybe you ran that command an hour ago, and now your history is full of other things. So you press Ctrl + R and type ls -l. Bash finds it in your history. You press Enter and it runs.
